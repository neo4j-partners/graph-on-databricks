# Semantic Investigation Copilot

This directory contains the focused semantic demo described in
`../work-proposals/finance-demo.md`.

The first version maps a small finance-investigation glossary to both:

- Databricks lakehouse tables and columns.
- Neo4j labels, relationships, properties, and provenance paths.

Planned artifacts include curated glossary definitions, source mappings,
validation results, and presenter instructions. Source record values must not be
stored here or copied into the semantic metadata graph.
